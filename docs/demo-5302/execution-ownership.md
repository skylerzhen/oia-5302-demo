# OIA 5302 Demo — Execution Ownership

## Agent-owned implementation

- Synthetic finance-role data package: job description, candidate profiles, MCQ,
  bilingual greeting, preset questions, and two distinct dynamic-follow-up paths.
- S1–S8 demo UI, audit trail, evidence links, local-only build, startup scripts,
  scene mapping, and fallback procedure.
- A deterministic 2D phoneme-to-viseme avatar fallback. It makes no claim of
  photorealistic generation or emotion recognition.
- Local integration adapters for OCR, LLM, ASR, and TTS once an execution host
  is available.

## Human-only verification or authority

- Physical external-network disconnection and network-monitor capture.
- Arabic native-speaker review and signed Gate 4 confirmation.
- Provisioning or approval of the actual GPU execution host.
- Project-scope sign-off and the 8/16 Go/No-Go decision.

## Default decisions while dependencies are pending

1. Keep the role as Senior Financial Analyst.
2. Use only synthetic candidate data.
3. Keep Jadarah actions visibly labelled `simulated endpoint`.
4. Use the deterministic 2D Avatar fallback until an approved rig is supplied.
5. Make every score evidence-linked and every hiring decision human-gated.
