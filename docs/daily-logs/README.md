# 每日工作日志

本目录记录 OIA RFQ 5302 项目每天的工作内容，供三台电脑 + Cursor 跨机同步时查阅。

## 怎么用

**你只需要每天对 Cursor 说一个字：**

> **收工**

AI 会自动：看今天改了什么 → 写 `docs/daily-logs/YYYY-MM-DD.md` → commit → push GitHub。  
另外两台电脑 `git pull` 即可。

也可说：「写日志」「今天结束了」「daily log」

### 手动备用（AI 已写日志后）

```bash
./scripts/end-of-day.sh
```

## 文件命名

```
docs/daily-logs/2026-08-15.md
```

## 日志模板

复制下面结构给 AI，或让 AI 自动按此格式写：

```markdown
# YYYY-MM-DD 工作日志

## 今日目标

## 完成事项

## 代码 / 文档变更

## 遇到的问题与解决

## 明日计划

## 备注（演示 / 客户 / 风险）
```
