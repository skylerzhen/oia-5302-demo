# 每日工作日志

本目录记录 OIA RFQ 5302 项目每天的工作内容，供三台电脑 + Cursor 跨机同步时查阅。

## 怎么用

1. **每天结束** 在 Cursor 里告诉 AI：「写今天的工作日志」
2. AI 会在此目录新增 `YYYY-MM-DD.md`
3. 你 `git add` → `commit` → `push` 后，另外两台电脑 `git pull` 即可同步

## 文件命名

```
docs/daily-logs/2026-08-15.md
```

## 日志模板

复制下面结构给 AI，或让 AI 自动按此格式写：

```markdown
# YYYY-MM-DD 工作日志

## 今日目标

## 完成事项

## 代码 / 文档变更

## 遇到的问题与解决

## 明日计划

## 备注（演示 / 客户 / 风险）
```
