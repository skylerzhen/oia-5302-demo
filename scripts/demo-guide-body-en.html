Platform Test & Operation Guide

This guide explains how testers can use one browser with two tabs to play the roles of candidate and HR recruiter, and verify live interview coordination, question push, replay, and final decision workflows.

Test Procedures

Before you begin

  • Use Chrome or Edge with two tabs in the same browser window (do not use incognito mode or separate browsers)
  • Open oia-recruitment.uiscloud.cc and click Reset demo to clear any previous session data
  • Arrange windows side by side: left = Candidate, right = HR, for easier switching
  • C4 AI interview requires microphone permission; the first connection after API cold start may take 30–60 seconds
  • This is a demonstration environment. Jadarah and Oracle EBS integrations are simulated and labelled accordingly in the UI

Dual-tab live interview (primary test scenario)

Objective: One tester alternates between two tabs to verify that the candidate C4 AI interview and the HR H1 live monitor / question push stay synchronised.

  1. Tab A (Candidate): Landing → Candidate portal → complete MFA sign-in (copy the 6-digit code shown on screen) → arrive at C1 Application
  2. Tab B (HR): Open a new tab to the same URL → HR / Recruiter portal → MFA sign-in → open H1 Review queues
  3. Tab A: On C1, upload a CV (or click Demo sample to load Sara) → on C2 click Submit profile
  4. Tab B: Switch to H1 — the applicant should appear in the queue. If not, refresh Tab B or wait 2 seconds and switch back
  5. Tab A: Complete C3 Technical assessment and click Submit
  6. Tab A: Open C4 AI interview — do not click Start yet
  7. Tab B: Scroll down on H1 to Live interview monitor (may show “Waiting for candidate to start C4…”)
  8. Tab A: Click Start interview, allow microphone access, and wait for the LiveAvatar video to appear
  9. Tab B: Live monitor status should change to Live, with Avatar and Candidate transcript lines appearing
  10. Tab A: Answer the first question by voice or text; wait for the avatar to finish speaking before responding
  11. Tab B: Confirm a new Candidate line appears in the transcript (syncs automatically — no refresh needed)
  12. Tab B: In Push next avatar question, enter an English question such as Tell me about your experience with document automation. → click Queue for next turn
  13. Tab A: Continue to the next turn — the avatar should ask the HR-pushed question (HR questions take priority over the default question bank)
  14. Repeat steps 10–13 for 2–3 rounds until C4 shows interview complete or Submit / proceed to C5
  15. Tab B: When Live monitor shows Submitted → click Open full replay (H3) or navigate to H3 via the sidebar
  16. Tab B: On H3, review turn-by-turn transcript, dimension scores, and Play recording (text-to-speech replay)
  17. Tab A: Open C5 Match insights and confirm the three-pillar composite score is displayed

Tab-switching tips (solo testing)

  • Use Alt+Tab / Ctrl+Tab to switch between tabs; on the HR side, watch for a new transcript line as the sync signal
  • Follow this rhythm: A acts → B verifies → B acts (push question) → A continues
  • Do not click Load demo application on Tab B mid-interview — it will overwrite the active session
  • If Tab B stays blank: confirm same browser, Tab A has submitted profile + completed C3, C4 has started, and at least one turn has completed

Quick interview test (skip C1–C3)

  • Tab A: Landing → Journey test channel → MFA → click Jump to C4 interview ready
  • Tab B: HR portal → H1 → Load demo application (preload only if Tab A has not started; for dual-tab tests, let Tab A drive the flow)
  • Then begin from step 7 above to test Live monitor and question push

Additional required checks

  • Cross-portal consistency: After Tab A completes C2, Tab B H1 queue and CV summary update
  • Connection recovery: If C4 video goes black, click Reconnect video; if that fails, use Restart interview
  • H2 screening: Shortlist or Decline with written rationale
  • H4 final decision: Adjust pillar weights → Hire or Reject → Tab A C6 shows the outcome
  • Journey J12: Open C6 and H5 in separate tabs and confirm the same applicant status
  • Simulated integrations: After profile submit, assessment, or final decision, check the sidebar integration panel for Jadarah / Oracle EBS sync events (simulated endpoints)

Pass criteria (interview segment)

  • Tab B Live monitor shows Live during C4, and transcript grows after each Tab A response
  • HR-queued English questions are asked by the avatar on Tab A’s next turn
  • After interview completion, H3 shows complete turns and Play recording works
  • Tab A C5 and Tab B H3 refer to the same applicant and the same turn content

1. Environment

Hosted demo

  • Web application: oia-recruitment.uiscloud.cc
  • API services: oia-5302-demo.onrender.com (LiveAvatar Lite, LLM scoring, TTS)
  • C4 avatar interview requires network connectivity; offline mode supports UI walkthrough only

Browser recommendations

  • Latest Chrome or Edge; microphone permission required for C4
  • For dual-portal testing, open two tabs — application data syncs automatically via shared browser storage

2. Three Entry Points

Landing page options

  • Candidate portal — candidate journey C1–C6 (Jadarah-style token sign-in, simulated)
  • HR / Recruiter portal — recruiter journey H1–H5 (OIA SSO + MFA, simulated)
  • Journey test channel — UIS 12-step acceptance navigator

Demo sign-in

  • Credentials are pre-filled → click Continue to MFA
  • Copy the 6-digit verification code shown on screen → click Verify and enter portal
  • Exit portal returns to Landing without clearing application data
  • Reset demo clears the session — use before testing if stale data is present

3. End-to-End Reference Path

Full workflow overview (see interview steps above for C4 detail)

  • Tab A: Candidate → C1 upload CV → C2 confirm profile → C3 assessment → C4 interview
  • Tab B: HR → H1 review queue; during C4 use Live interview monitor for real-time transcript
  • After interview: Tab B → H3 replay; Tab A → C5 composite score; HR → H2/H4 decisions; Tab A → C6 outcome

Shortcut paths

  • Journey channel: Load demo application (Sara)
  • Jump to C4 interview ready
  • HR H1: Load demo application to preload Sara (can jump directly to H3 for replay testing)

4. Candidate Steps (C1–C6)

C1 · Application

  • Upload a sample CV (PDF/HTML); after parsing completes, proceed to C2

C2 · Profile review

  • Review and edit extracted fields; Submit profile unlocks C3 and triggers simulated Jadarah profile write-back

C3 · Technical assessment

  • Fixed multiple-choice question bank with automatic scoring; result syncs to simulated Jadarah assessment endpoint

C4 · AI interview (LiveAvatar Lite)

  • Start interview establishes a LiveAvatar Lite session
  • Candidate view shows avatar video, current caption, and controls only — no side transcript history panel
  • If video disconnects: Reconnect video; if session stalls: Restart interview
  • Completion unlocks C5

C5 · Match insights

  • Three-pillar weighted composite, six-dimension evidence, and improvement recommendations

C6 · Application status

  • Displays Hire/Reject outcome after HR H4 final decision

5. HR Steps (H1–H5)

H1 · Review queues

  • Ranked applicant list, CV summary, Interview setup (JD + custom questions)
  • Live interview monitor: real-time text transcript during C4
  • Queue for next turn: HR pushes the next avatar question in English

H2 · Screening decision

  • Shortlist or Decline with written rationale (Decline label: Below screening threshold)

H3 · Interview review

  • Turn-by-turn transcript plus LLM dimension evaluation
  • Play recording replays the text transcript via TTS — not original audio/video capture

H4 · Final decision

  • Adjust pillar weights, record Hire/Reject with rationale; outcome syncs to C6 and simulated Jadarah / Oracle EBS endpoints

H5 · Audit and export

  • Audit timeline including integration sync events

6. Scoring Alignment

What testers should verify

  • Three pillars: CV match, technical assessment, and interview performance — weights are shared between candidate C5 and HR H4
  • When HR adjusts pillar weights on H4, candidate C5 composite score updates to match (same browser storage)
  • Dimension-level scores on H3 and evidence bars on C5 should reference the same applicant and assessment data
  • Technical assessment (C3) uses a fixed question bank with automatic scoring; interview dimensions (C4/H3) use LLM evaluation

8. Frequently Asked Questions

HR portal does not show candidate data?

  • Use two tabs in the same browser; refresh the HR tab or re-enter the portal
  • During an active C4 interview, use H1 Live monitor — not H3

C4 black screen or cannot start?

  • Wait for API cold start (approximately 30–60 seconds); try Reconnect video or Restart interview
  • Confirm microphone permission and LiveAvatar Lite service availability

H3 replay differs from the live session?

  • Play recording replays the text transcript via TTS; original audio/video is not stored in this demo

Offline indicator in the top bar?

  • Landing page can simulate offline mode for UI testing; C4 LiveAvatar requires live connectivity

Are Jadarah and Oracle EBS connections live?

  • No — this demo uses simulated endpoints clearly labelled in the UI. Production deployment would connect to live Jadarah and Oracle EBS systems.
