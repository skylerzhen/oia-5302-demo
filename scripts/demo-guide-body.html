平台操作指南

教测试员如何在一个浏览器、两个标签里分别扮演候选人与 HR，完成 Live 面试联动、推题、回放与终审验收。

双标签C4 面试Live monitorHR 推题H3 回放

测试操作指南

开始之前

  • 使用 Chrome 或 Edge，准备 两个标签页（同一浏览器，不要无痕/不同浏览器）
  • 打开 oia-recruitment.uiscloud.cc，先点 Reset demo 清空旧数据
  • 建议窗口 左右并排：左 = 候选人，右 = HR，方便来回切换
  • C4 面试需允许麦克风；API 冷启动时首轮连接可能需等 30–60 秒

一人模拟双端：Live 面试交互（重点）

目标：同一个人交替操作两个标签，验证「候选人 C4 面试」与「HR H1 实时监控 / 推题」是否联动。

  1. 标签 A（候选人）：Landing → Candidate portal → MFA 登录（复制页面 6 位码）→ 进入 C1
  2. 标签 B（HR）：新开标签，同一网址 → HR / Recruiter portal → MFA 登录 → 进入 H1 Review queues
  3. 标签 A：C1 上传 CV（或点 Demo sample 加载 Sara）→ C2 Submit profile
  4. 标签 B：切回 H1，应看到该申请人出现在队列；若无，刷新 B 或等 2 秒再切回
  5. 标签 A：进入 C3 Technical assessment，答完并 Submit
  6. 标签 A：进入 C4 AI interview，先不要点 Start
  7. 标签 B：在 H1 页面向下找到 Live interview monitor（此时可能显示 Waiting for candidate to start C4…）
  8. 标签 A：点击 Start interview，允许麦克风；等 Avatar 视频出现
  9. 标签 B：Live monitor 应变为 Live，并开始出现 Avatar / Candidate 文字行
  10. 标签 A：用语音或文字回答第一轮问题，等 Avatar 说完再答
  11. 标签 B：确认 transcript 新增 Candidate 行（与 A 侧同步，无需刷新）
  12. 标签 B：在 Push next avatar question 输入英文问题，如 Tell me about your experience with document automation. → 点 Queue for next turn
  13. 标签 A：继续下一轮；Avatar 应优先念出 B 刚推送的问题（非默认题库时以 HR 题为准）
  14. 重复 10–13 共 2–3 轮，直至 C4 显示面试完成或出现 Submit / 进入 C5
  15. 标签 B：Live monitor 显示 Submitted → 点 Open full replay (H3) 或侧栏进 H3
  16. 标签 B：H3 检查逐轮 transcript、维度分、Play recording（TTS 重演）
  17. 标签 A：进入 C5 Match insights，确认有三柱分数

窗口切换技巧（一个人测时不乱）

  • Alt+Tab / Ctrl+Tab 在两个标签间切换；HR 侧以「看 transcript 是否多一行」为同步信号
  • 操作顺序永远是：A 行动 → B 验证 → B 行动（推题）→ A 继续
  • 不要在面试中途对 B 标签点 Load demo application，会覆盖 A 正在进行的会话
  • 若 B 一直空白：确认同浏览器、A 已 Submit profile + 完成 C3、C4 已 Start 且至少有一轮 turn

快捷测面试（跳过 C1–C3）

  • 标签 A：Landing → Journey test channel → MFA → 点 Jump to C4 interview ready
  • 标签 B：HR portal → H1 → Load demo application（仅当 A 尚未开始时用于预载；双端联测时优先让 A 自己推进）
  • 然后直接从上面步骤 7 开始测 Live monitor + 推题

其他必测项（清单）

  • 双端记录一致：A 填完 C2 后 B 的 H1 队列与 CV 摘要更新
  • 断线恢复：C4 视频黑屏时点 Reconnect video；仍失败则 Restart interview
  • H2 初筛：Shortlist / Decline + 理由
  • H4 终审：调权重 → Hire/Reject → A 的 C6 显示结果
  • Journey J12：双标签分别打开 C6 与 H5，确认同一申请人状态

测试通过标准（面试段）

  • B 的 Live monitor 在 C4 进行中显示 Live，且每轮 A 回答后 transcript 增加
  • HR Queue 的英文题能在 A 下一轮被 Avatar 问到
  • 面试结束后 H3 有完整 turns，Play recording 可播放
  • A 的 C5、B 的 H3 对应同一申请人、同一轮次内容

1. 启动与环境

线上演示

  • 前端：oia-recruitment.uiscloud.cc
  • API：oia-5302-demo.onrender.com（LiveAvatar / LLM / TTS）
  • C4 数字人面试需联网；离线模式仅 UI

浏览器建议

  • Chrome / Edge 最新版；C4 需允许麦克风
  • 双 portal 演示开两个标签页，数据自动同步

2. 三个入口

Landing 选择

  • Candidate portal — 候选人 C1–C6
  • HR / Recruiter portal — 招聘官 H1–H5
  • Journey test channel — UIS 12 步验收导航

Mock 登录

  • 预填账号 → Continue to MFA
  • 复制页面上 6 位验证码 → Verify and enter portal
  • Exit portal 回 Landing，不清空申请数据
  • Reset demo 清空会话，演示前遇旧数据可先 Reset

3. 全流程参考路径

完整流程概览（面试段见上文步骤）

  • 标签 A：Candidate → C1 上传 CV → C2 确认档案 → C3 测评 → C4 面试
  • 标签 B：HR → H1 看队列；C4 进行中用 Live interview monitor 看 transcript
  • 面试后：B → H3 回放；A → C5 综合分；HR → H2/H4 决策；A → C6 结果

快捷路径

  • Journey：Load demo application (Sara)
  • Jump to C4 interview ready
  • HR H1：Load demo application 预载 Sara（可直跳 H3）

4. 候选人步骤（C1–C6）

C1 · Application

  • 上传 PDF/HTML 样例 CV；解析完成后进入 C2

C2 · Profile review

  • 确认/编辑提取字段；Submit profile 后解锁 C3

C3 · Technical assessment

  • 固定 MCQ 题库自动评分

C4 · AI interview

  • Start interview 建立 LiveAvatar 会话
  • 仅 Avatar 字幕 + 控件，不展示右侧历史 transcript 列表
  • 视频断开：Reconnect video；卡死：Restart interview
  • 完成后解锁 C5

C5 · Match insights

  • 三柱加权合成、六维度证据与改进建议

C6 · Application status

  • HR H4 终审后显示 Hire/Reject 结果

5. HR 步骤（H1–H5）

H1 · Review queues

  • 排名、CV 摘要、Interview setup（JD + 自定义问题）
  • Live interview monitor：C4 实时文字 transcript
  • Queue for next turn：HR 推送下一道 Avatar 英文题

H2 · Screening decision

  • Shortlist / Decline + 书面理由（Decline 文案为 Below screening threshold）

H3 · Interview review

  • 逐轮 transcript + LLM 评估
  • Play recording = TTS 重演文字，非原始录音

H4 · Final decision

  • 调权重、Hire/Reject，同步至 C6

H5 · Audit and export

  • 审计时间线

7. 常见问题

HR 看不到候选人数据？

  • 同一浏览器双标签；刷新 HR 或重开 portal
  • C4 进行中看 H1 Live monitor，不是 H3

C4 黑屏 / 无法开始？

  • 等 API 冷启动（约 30–60 秒）；Reconnect video 或 Restart interview
  • 检查麦克风权限与 LiveAvatar 配额

H3 回放与现场不同？

  • 系统按文字记录重新播放，不存原始音视频

顶栏 Offline 灯？

  • Landing 可模拟离线；C4 LiveAvatar 真实离线时不可用
