# OIA 5302 — Senior Financial Analyst Assessment Bank

**Scope:** Synthetic, bilingual MCQ set for S5  
**Scoring:** 1 point per correct answer; four questions; 70% comparison benchmark  
**Controls:** The candidate sees only their own result. This is not a proctoring
or anti-cheating claim.

## Q1 — Portfolio concentration risk

**English:** Which metric best measures portfolio concentration risk?  
**Arabic:** أي مقياس يقيس مخاطر تركز المحفظة بشكل أفضل؟

1. Herfindahl index **(correct)**
2. Current ratio
3. Gross margin
4. Working capital

## Q2 — Quarterly variance reporting

**English:** A quarterly variance report should primarily explain:  
**Arabic:** يجب أن يشرح تقرير التباين ربع السنوي بشكل أساسي:

1. Changes versus the prior forecast or benchmark **(correct)**
2. Only total assets
3. HR headcount only
4. Office lease terms

## Q3 — Bilingual board communication

**English:** When presenting to a bilingual board, the best practice is:  
**Arabic:** عند العرض على مجلس ثنائي اللغة، أفضل ممارسة هي:

1. Consistent figures with aligned English and Arabic narrative **(correct)**
2. An Arabic-only appendix hidden from auditors
3. Removing risk disclosures
4. Using unaudited projections only

## Q4 — Controlled financial models

**English:** Excel models for financial forecasting should:  
**Arabic:** يجب أن تكون نماذج Excel للتنبؤ المالي:

1. Separate inputs, calculations and outputs with version control **(correct)**
2. Hard-code all assumptions in one cell
3. Disable audit trails
4. Share editable files without controlled assumptions

## Required S5 output

The assessment view must display:

1. Score
2. Accuracy
3. Duration
